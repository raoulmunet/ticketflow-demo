# TicketFlow — Synthetic Basic Demo

A standalone, client-side functional simulation. No account or backend required.

## Privacy warning

Do not enter confidential or personal information. Use fictional text only.
Changes exist in page memory and are discarded on reset or reload.
All shipped fixtures, including internal-note examples, are public and inspectable.
The simulated role selector is not authentication or access control.
Hosting providers and browsers may process ordinary request metadata; this demo
does not promise anonymity or protection from browser extensions.

## Explore

Open index.html through a local static HTTP server or an approved static host.
Keep the HTML, CSS and both JavaScript files together.

- Requester: fictional owned tickets, creation, public discussion, close/reopen/cancel.
- Agent: fictional assigned tickets, discussion, start work and propose resolution.
- Manager: fictional queue, triage, initial assignment and limited reassignment.
- Dashboard, filters, discussion/history and reset are included.
- Closed and cancelled tickets are read-only.
- Agent B is an assignment target, not another selectable persona.

All users, tickets, teams, comments and history are synthetic.
The fixed clock is 15 October 2026, 12:00 UTC, not a live SLA monitor.

## Guided Tour

Choose **Take a Tour** for eight short steps covering the fictional-data warning,
simulated roles, dashboard, filters, creation, ticket context, discussion/history
and available actions. Use Back, Next, Skip or Finish; Escape closes the tour.
The tour keeps your current role and opens only an already-visible synthetic ticket.
It never creates tickets, submits forms, changes assignments or saves data.
Finish or manually discard unsaved drafts before starting. Changing route/role
or resetting fixtures closes the tour. It supports keyboard navigation, mobile
layouts and reduced motion. Restart it at any time when no draft is pending.

## Limitations

No Oracle, APEX, backend connection, persistence, real authentication or authorization.
No uploads, attachments, exports, notifications or production identity switching.
Client-side filtering is only a demonstration, not confidentiality enforcement.
Do not reuse this model as a production security boundary.
Reset or reload restores the deterministic fixtures.
Offline functional tests do not establish production security or deployment readiness.

This distribution contains only index.html, prototype.css, demo-model.js,
prototype.js and this README. No development history or internal evidence is included.
